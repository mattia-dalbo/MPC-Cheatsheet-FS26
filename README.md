# MPC Cheatsheet — FS26

Cheat sheet for the Model Predictive Control (MPC) course, FS26, ETH Zürich. Written in LaTeX.

## Authors
- Andrea Bernasconi
- Filippo Frigerio
- Mattia Dal Bò

## Contents
This summary covers:
- Discretization & Linearization
- LQR
- Convex Optimization
- Nominal MPC (CFTOC, Invariance, Explicit MPC)
- Robust MPC (Constraint-tightening, Tube MPC)
- Implementation methods (Explicit solution, Interior-point, Active-set)

## Compiling
Requires a LaTeX distribution (e.g. TeX Live, MiKTeX) or [Overleaf](https://overleaf.com). Compile `main.tex` with pdfLaTeX.
